Installation & Setup
Clone the Repository
git clone https://github.com/cyrilchris-j/reminder.git
Navigate to Project Folder
cd reminder
Install Dependencies
npm install
Start Development Server
npm run dev
Firebase Deployment
Build the Project
npm run build
Deploy to Firebase
firebase deploy
